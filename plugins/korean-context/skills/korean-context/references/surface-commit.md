# Commit

## Audience

변경 이력을 훑는 개발자.

## Default register

짧은 phrase. 저장소 convention이 우선한다.

## Rules

- 실제 변경과 대상을 앞에 둔다.
- 입력에서 영문으로 쓴 기술 표기는 일반명처럼 보여도 보존한다. `canvas`를 `캔버스`, `sidebar`를 `사이드바`로 음역하지 않는다.
- 식별자를 특정 코드 구성 요소나 계층으로 옮긴 변경은 프로젝트 매핑이 없는 한 입력에 나온 식별자와 대상 구성 요소의 영문 표기를 보존한다.
- 저장소가 정한 용어를 그대로 쓰고 일반 영문 표현으로 되돌리지 않는다.
- 저장소 관례나 사용자가 요구하지 않은 Conventional Commit 접두사를 추가하지 않는다.
- 제목만으로 부족할 때만 body에 이유와 검증을 쓴다.

## Avoid

`진행`, `수행`, 확인하지 않은 효과, 장황한 완전문.

## Examples

- `sidebar 너비를 제외한 canvas 중앙 영역 계산 보정`
- `캐시 무효화 로직 단순화`
- 기존 함체: `캐시 만료 검사 추가함`
