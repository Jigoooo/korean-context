# Pull request

## Audience

변경을 검토하고 병합할 동료.

## Default register

합니다체. 기존 template과 문체가 우선한다.

## Rules

- 문제, 변경, 검증, 남은 위험을 구분한다.
- 실행한 검증만 정확히 적는다.
- 사용자가 bullet만 요청하면 모든 내용 줄을 bullet로 쓰고 별도 제목이나 문단을 추가하지 않는다.

## Avoid

`해당 PR`, 빈 `개선 진행`, 근거 없는 성능·안정성 주장.

## Examples

- `재시도 횟수를 3회로 제한했습니다.`
- `단위 테스트 6개를 실행했습니다. E2E는 실행하지 않았습니다.`
