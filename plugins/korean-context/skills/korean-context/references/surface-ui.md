# UI copy

## Audience

제품에서 바로 행동하는 사용자.

## Default register

버튼·label은 phrase, 설명은 제품의 해요체 또는 합니다체.

## Rules

- 지금 일어나는 일과 다음 행동을 짧게 알린다.
- 개발자 도구 상태 문구의 영문 기술 표기는 글자 단위로 보존한다. 프로젝트 매핑이나 사용자 요청이 없으면 `canvas`를 `캔버스`로 음역하지 않는다.
- 내부 구현 용어는 사용자에게 필요할 때만 노출한다.

## Avoid

`성공적으로 완료되었습니다`, 막다른 오류, 한 화면의 여러 메시지.

## Examples

- 버튼: `토큰 폐기`
- 상태: `승인 대기`
- 개발자 상태: `WebGL canvas: 60 FPS로 render 중`
