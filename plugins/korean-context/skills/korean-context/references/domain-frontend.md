# Frontend

## Audience

웹·앱 frontend 개발자와 제품 사용자.

## Default register

선택한 surface의 register.

## Rules

- render, hydration, focus, hover, autofill, state의 동작 차이를 보존한다.
- accessibility 용어는 대상 독자에 따라 accessible name과 접근 가능한 이름을 병기한다.

## Avoid

focus를 `집중`으로 기계 번역, state를 모든 문맥에서 `상태값`으로 고정.

## Examples

- `input에 focus가 생기면 텍스트 색상을 유지한다.`
