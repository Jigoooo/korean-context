# Artifact boundary

## Purpose

한국어가 있다는 이유가 아니라 텍스트의 목적지로 적용 여부를 결정한다.

## Rules

- 커밋, PR, 이슈, 리뷰, 코드 주석, 문서, UI 문구, 오류, 테스트 이름, 변경 기록처럼 저장되거나 게시될 텍스트에 적용한다.
- 일반 대화, 진행 상황, 계획, 설명, 질문, 기술 Q&A에는 적용하지 않는다.
- 명시적으로 스킬을 호출해도 목적지가 일반 대화면 산출물 교정으로 바꾸지 않는다.
- 일반 대화에서는 평소처럼 직접 답하고 스킬 이름, 활성화 여부, 적용하지 않은 이유를 언급하지 않는다.
- 스킬을 적용하기 위해 workspace를 조사하거나 입력에 없는 과거 프로젝트 사실과 파일 링크를 덧붙이지 않는다.
- 한 응답에 설명과 산출물 초안이 함께 있으면 초안에만 적용한다.
- 사용자가 결과를 파일이나 외부 시스템에 남기려는지 불분명하면 문맥으로 판단하고, 판단이 결과를 크게 바꾸면 짧게 확인한다.
- 사용자가 충분한 맥락과 함께 산출물 작성을 요청하면 현재 작업공간을 조사하거나 자료가 없다는 설명을 붙이지 않고 요청된 산출물을 바로 작성한다.

## Counterexamples

- "왜 이 구조가 필요한지 설명해줘"는 일반 대화다.
- "README에 이 구조가 필요한 이유를 써줘"는 문서 산출물이다.
- "PR을 어떻게 쓰면 좋아?"는 조언이다.
- "이 diff의 PR 본문을 써줘"는 PR 산출물이다.

## Same-generation check

대화 부분까지 문체를 교정하지 않았는지, 산출물의 목적지를 정확히 식별했는지 확인한다.
