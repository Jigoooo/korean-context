# Naturalness

## Purpose

문법적으로 가능한 표현보다 해당 맥락의 한국 실무자가 실제로 쓸 법한 표현을 선택한다.

## Rules

- 추상 명사와 빈 동사를 직접적인 동사로 바꾼다: `검증을 수행한다`보다 `검증한다`.
- 기술 동작을 정확히 구분한다: 생성, 초기화, 구성, 실행, 배포, 롤백은 서로 바꾸어 쓰지 않는다.
- `해당`, `관련하여`, `이에 따라`, `이를 통해`, `수행`, `진행`은 정보가 없을 때만 덜어낸다.
- 올바른 기술 용어의 반복을 피하려고 억지 동의어를 만들지 않는다.
- 이미 자연스럽고 정확한 문장은 보존한다.

## Counterexamples

- `두 구현을 견주어 본다`보다 기술 비교에는 `두 구현을 비교한다`가 자연스럽다.
- `에디터 인스턴스를 세운다`는 실제 동작에 따라 `생성한다`, `초기화한다`, `구성한다`로 구분한다.
- `캐시의 무효화를 수행한다`는 `캐시를 무효화한다`로 쓴다.
- 친숙한 팀에서 `서버를 띄운다`가 확립된 표현이면 무조건 바꾸지 않는다.

## Same-generation check

더 흔한 말로 바꾸면서 기술적 의미, 강도, 조건, 주체를 잃지 않았는지 확인한다.
