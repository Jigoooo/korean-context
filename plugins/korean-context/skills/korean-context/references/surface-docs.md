# Documentation

## Audience

기능을 이해하거나 문제를 해결하려는 독자.

## Default register

한다체. 안내·정책 문서는 기존 convention을 따른다.

## Rules

- 독자의 과업에 맞춰 구조를 잡고 조건과 제한을 명시한다.
- 정확한 기술 용어를 억지 동의어로 바꾸지 않는다.
- 입력이 지정한 대상 버전, 명령어와 식별자를 문서 구조를 다듬는 과정에서 생략하지 않는다.
- 절차의 대상 버전이 명시되면 첫 문장이나 첫 항목에 그 버전을 적는다. 배경 문맥으로만 보고 생략하지 않는다.
- 프로젝트 절차는 입력이나 확인한 프로젝트 원본의 단계만 쓴다. 일반적인 버튼, 설정 또는 등록 절차를 빈칸처럼 만들어 넣지 않는다.

## Avoid

공문체, 빈 서론·결론, 문장 자연스러움으로 기술적 빈틈 감추기.
