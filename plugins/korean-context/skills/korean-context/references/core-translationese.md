# Translationese

## Purpose

영어 문장 구조를 한국어 단어로 옮긴 흔적을 맥락에 따라 줄인다.

## Rules

- 기계적인 `의`, `~에 대한`, `~에서의` 연결을 목적격이나 직접 수식으로 바꾼다.
- 원문에 필요 없는 `그`, `그녀`, `그것`, `그들`을 반복하지 않는다.
- 긴 왼쪽 수식어는 조건과 핵심 동작을 나눈다.
- 주체가 분명하면 불필요한 피동과 이중 피동을 능동형으로 바꾼다.
- 영어식 명사열은 관계가 드러나도록 풀되 식별자와 고유 용어는 보존한다.
- 연결 표현을 지우면 논리 관계가 사라지는 경우에는 유지한다.

## Counterexamples

- `요청에 대한 검증을 수행한다`는 `요청을 검증한다`로 쓴다.
- `상태가 컴포넌트에 의해 변경되어집니다`는 `컴포넌트가 상태를 바꿔요`로 쓴다.
- 행위 주체를 숨겨야 하거나 결과 상태가 핵심이면 피동을 유지할 수 있다.

## Same-generation check

조사와 피동을 줄인 뒤 인과, 조건, 행위 주체가 원문과 같은지 확인한다.
