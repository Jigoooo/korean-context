# Software

## Audience

소프트웨어 개발자와 기술 사용자.

## Default register

선택한 surface의 register.

## Rules

- create, initialize, configure, execute, deploy를 실제 동작으로 구분한다.
- API, SDK, CLI, runtime, parser, cache, fallback은 통용 표기를 우선한다.

## Avoid

`세우다`의 기계적 사용, fallback의 `후퇴 경로` 고정 번역.

## Examples

- `parser를 초기화한다`, `캐시를 무효화한다`
