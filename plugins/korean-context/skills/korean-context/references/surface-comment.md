# Source comment

## Audience

나중에 코드를 수정할 개발자.

## Default register

한다체. 파일의 기존 문체가 우선한다.

## Rules

- 코드가 보이는 동작보다 이유, 제약, 예외를 설명한다.
- 식별자와 조건을 정확히 보존한다. 프로젝트 매핑이 없으면 `pointer` 같은 영문 코드 식별자를 한국어 음역으로 바꾸지 않는다.
- 사용자가 주석만 요청하면 주석 줄만 반환한다. Markdown code fence나 설명을 덧붙이지 않는다.

## Avoid

코드 직역, 오래될 구현 세부, `처리를 수행한다`.

## Examples

- `같은 요청의 중복 결제를 막기 위해 기존 결과를 반환한다.`
