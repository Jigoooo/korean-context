# Reference mining

Korean Context는 원문 문장을 모아 재배포하지 않는다. `sources.yml`에는 공개 자료에서 확인한 사용 경향, 용어 상태, 문체, 실패 패턴과 이를 일반화한 결정만 기록한다.

## Evidence order

1. 한국 실무자가 한국어로 직접 작성한 기술·제품·보안 글
2. 한국 기관과 기업의 공식 한국어 자료
3. 한국 오픈소스 협업 및 전문 커뮤니티 자료
4. 번역 자료와 기존 AI 작성 스킬은 보조 근거

한 회사의 말투를 보편 규칙으로 취급하지 않는다. 서로 다른 조직과 표면에서 같은 경향이 확인되는지 비교하고, 널리 쓰이는 복수 형태는 하나를 오답으로 만들지 않는다.

## Copyright

출처 URL과 독립적으로 작성한 요약만 저장한다. 긴 인용문, 기사 본문, 유료 자료, 개인 데이터는 저장하지 않는다.
