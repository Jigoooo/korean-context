# Korean Context v0.1.0

Codex에서 한국어 software artifact의 표현, 기술 용어와 문체를 맥락에 맞추는 첫 prerelease입니다.

## Included

- commit, PR, issue, review, comment, docs, UI, error, test, release reference
- software, frontend, backend, infra, common security, AppSec, vulnerability, pentest/red-team reference
- 100-case corpus와 실제 live 30-case 비교

## Result

- explicit: 30/30, 9.97/10, hard failure 0, unnecessary rewrite 0
- implicit: 30/30, 9.87/10, hard failure 0, unnecessary rewrite 1
- clear repair gains over strong baseline: 4/10

## Privacy

자동 사용자 학습, 산출물 업로드, background LLM, runtime network dependency가 없습니다. 일반 assistant conversation은 적용 범위가 아닙니다.

## Limitation

Codex만 검증했습니다. explicit invocation을 권장하며 implicit activation은 beta입니다. 결과는 수동 rubric과 작은 고정 표본을 기반으로 하므로 다른 model/version에서 달라질 수 있습니다.
