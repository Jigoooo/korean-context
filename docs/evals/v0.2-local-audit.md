# v0.2 로컬 저장소 검사

로컬 검사는 공개 fixture를 보완하는 읽기 전용 확인 절차다. 비공개 source와 원본 출력은 `.local/evals/v0.2/` 아래에만 두며 Git에 추가하지 않는다.

## Source manifest

기본 manifest 경로는 `.local/evals/v0.2/source-manifest.json`이다.

```json
{
  "repositoryRoot": "<repository-root>",
  "baseRef": "<reviewed-ref>",
  "cases": [
    {
      "id": "local-001",
      "relativePath": "src/example.ts",
      "startLine": 10,
      "endLine": 14,
      "surface": "comment",
      "domain": "frontend",
      "instruction": "선택한 코드 주석을 검토해줘.",
      "projectVocabulary": {
        "preferred": ["위젯"],
        "accepted": [],
        "forbidden": ["컴포넌트"]
      },
      "protectedTokens": ["AbortController"],
      "repeatCount": 1
    }
  ]
}
```

`repositoryRoot`는 검사할 checkout을 가리킨다. `baseRef`는 prompt에 기록하는 검토 기준이며 checkout을 전환하지 않는다. `relativePath`에는 저장소 안의 UTF-8 텍스트 파일만 지정할 수 있다. 절대 경로, root를 벗어나는 경로, binary 파일과 범위를 벗어나는 줄 번호는 거부한다.

## 실행

```powershell
pnpm eval:v0.2:local -- --mode baseline
pnpm eval:v0.2:local -- --mode explicit
```

필요하면 `--manifest`, `--model`, `--reasoning-effort`, `--output`을 지정한다. `--output`은 현재 프로젝트의 `.local` 안에 있어야 하며 기본값은 `.local/evals/v0.2/<mode>/runs.jsonl`이다.

각 시도는 `codex exec --sandbox read-only`로 source 저장소에서 실행한다. 실행기는 선언된 모든 source 파일의 SHA-256과 `git status --porcelain=v1` 결과를 시도 전후에 비교한다. 하나라도 달라지면 시도를 실패시키고 해당 결과를 성공 기록으로 추가하지 않는다. 검사 전에 존재하던 수정 사항은 그대로 보존되어야 한다.

## 공개 범위

- 로컬 manifest, source 문맥과 원본 출력은 `.local/` 밖으로 복사하지 않는다.
- 공개 `evals/results/v0.2/`에는 익명화된 fixture로 실행한 결과만 저장한다.
- 로컬 검사는 공개 평가 실패를 덮거나 릴리스 게이트를 대신할 수 없다.
- 보고서에는 집계 수치와 확인 범위만 기록하며 비공개 경로, branch, commit, 식별자 또는 source 문장을 넣지 않는다.
